BOM·좌표데이터 비교

  1. BOM 파일과 좌표 데이터 파일을 선택합니다.
  2. 필요하면 시트 확인·변경을 엽니다. 좌표의 제목 행은 자동으로 찾으며, 틀리면 열 연결·제외·NC 설정에서 고칩니다.
  3. 제목 행 번호는 엑셀에 보이는 번호 그대로 입력합니다. 열 이름이 3행에 있으면 3입니다. 2로 바꾸지 않습니다.
  4. 자동으로 연결한 Location·품명·규격·Maker·단위수량과 좌표 RefDes·PCB Decal 열을 확인한 뒤 비교하기를 누릅니다.
  5. 확인 필요 숫자를 눌러 검토할 항목을 모아 봅니다. 검색창에서는 위치·품명·규격·제조사 등을 찾을 수 있습니다.
  6. 파일이나 조건을 바꾸려면 파일·설정 바꾸기를 누릅니다. 조건이 바뀌면 이전 결과를 숨기므로 다시 비교합니다.

결과를 읽는 방법

  • 매칭: 양쪽 파일에 위치가 있고, 자동으로 비교한 항목에서 차이를 찾지 못한 경우입니다. 판정근거가 ‘Location만’이면 규격은 확인되지 않았습니다.
  • 규격불일치: 크기·피치·패키지·선경 등 비교 가능한 정보가 다르거나 확인이 필요합니다. 원문에서 달라진 값은 빨간 글씨로, 판정근거에는 BOM/좌표 값을 나란히 표시합니다.
  • BOM만 / 좌표만: 한쪽 파일에만 있는 위치입니다. 누락·미실장·부속품인지 원본과 확인합니다.
  • BOM중복: 같은 위치가 여러 BOM 행에 있습니다. 표시되는 비교값은 마지막 행 기준이며 원본 중복 내역을 확인해야 합니다.
  • 좌표중복 확인: 같은 위치가 여러 좌표 행에 있어 판정을 보류합니다. 중복 안내에서 원본 행·규격·좌표를 확인하고 원본을 정리합니다. 엑셀에도 ‘좌표중복 점검’ 시트를 남깁니다.
  • NC: 좌표만 있는 항목 중 사용자가 미실장으로 지정한 위치입니다. 행의 NC지정 / NC해제 버튼이나 설정의 NC 입력란을 사용합니다. 행 체크박스는 저장할 항목 선택용입니다.

위치 매칭률과 제외 설정

위치 매칭률은 비교 대상 BOM 위치가 좌표 파일에도 있는 비율입니다. 규격불일치와 좌표중복도 위치 존재에는 포함됩니다. 100%가 규격 정상이나 실제 실장 완료를 뜻하지 않습니다.

TP·ICT는 초기 설정에서 제외합니다. FID·고정홀은 체크 여부에 따릅니다. 사용자가 바꾼 설정은 이 브라우저에 저장됩니다. FOR 부속품·대체품과 품명 제외 설정도 확인하세요.

Location에 C1,C2처럼 여러 위치를 적으면 각각 비교합니다. 단위수량 열을 연결하면 위치 개수와 수량 차이도 점검합니다. 전압·전류 등 BOM의 모든 사양을 좌표 데이터와 비교하는 기능은 아닙니다.

저장 범위

  • 전체 결과 엑셀 저장: 필터와 관계없이 전체 비교 결과를 저장합니다.
  • 현재 결과 저장: 현재 필터와 검색으로 보이는 행을 저장합니다.
  • 선택 저장: 행 체크박스로 선택한 항목을 저장합니다.

결과 수정·저장 옵션

결과 위의 결과 수정·저장 옵션에서 품명·규격을 수정할 수 있습니다. 수정 후 해당 행의 판정을 다시 계산합니다. 중복된 원본 위치는 먼저 원본을 정리해야 합니다.

  • BOM only 삭제: 좌표에 없는 위치만 출력에서 제외합니다. 한 행의 일부 위치만 제외하면 수량을 안전하게 나눌 수 있는지 검사합니다.
  • 좌표 only 추가: 해당 위치를 BOM 결과에 추가합니다. 알 수 없는 품번·품명·규격·제조사는 비워 두고 확인 필요로 표시합니다. 좌표 패키지명은 참고 열에 남깁니다.
  • 중복 제거: 부품 정보가 같고 수량 배분이 명확한 중복만 마지막 위치를 남깁니다. 다른 값·대체품 연결·불명확한 수량이 있으면 삭제하지 않고 저장을 중단합니다.
  • 변경 이력 로그: 삭제·추가·직접 수정 내역을 함께 저장합니다.

옵션 저장은 원본의 열과 데이터를 바탕으로 새 엑셀을 만듭니다. 원본 파일의 모든 폰트·병합·행 높이·열너비가 그대로 유지되는 것은 아닙니다.

BOM 이력비교

  1. 상단 BOM 이력비교 탭에서 기준 BOM(변경 전)과 비교 BOM(변경 후)을 올립니다.
  2. 시트·제목 행 확인에서 자동 선택을 확인합니다. 제목 행은 엑셀 번호 그대로 입력합니다.
  3. 필요하면 비교 설정에서 LOCATION 열과 비교에서 제외할 열을 지정합니다. 양쪽 공통 열을 비교하며 한쪽에만 있는 열은 안내합니다.
  4. 변경 내용 비교하기를 누릅니다. 기준과 비교를 반대로 넣었다면 기준·비교 바꾸기 후 다시 실행합니다.
  5. 전체 변경 / 본품·구성행 변경 / 규격 변경 / 추가 / 삭제 / 대체품 변경 숫자를 눌러 확인합니다. 대체품은 추가·삭제·변경을 따로 선택할 수 있습니다.
  6. 표의 기준 BOM과 비교 BOM을 대조합니다. 변경 전은 회색 취소선, 변경 후는 빨간 굵은 글씨로 달라진 부분만 강조합니다.
  7. 전체 결과 엑셀 저장을 누릅니다. 화면에서 필터·검색·묶어 보기를 사용해도 전체 결과를 저장합니다.

비교 기준과 건수

LOCATION을 기준으로 연결하고, 위치가 없는 PCB·ASSY는 품번·소속 관계 등으로 비교합니다. 연결 후보가 여러 개면 임의로 선택하지 않고 입력 점검에 표시합니다. 대체품은 본품과 품번을 함께 연결합니다.

‘규격 변경’은 전체 변경 중 규격이 바뀐 항목을 모은 것입니다. 카드 숫자를 모두 더하면 중복 집계됩니다. 같은 변경 묶기는 표시만 줄이며, 원본 행 번호는 각 항목의 상세 정보에서 확인합니다.

엑셀은 요약·변경된 부품·추가된 부품·삭제된 부품·대체품 변경·입력 점검으로 저장합니다. 한 부품에서 여러 항목이 바뀌면 저장 행 수가 화면 변경 건수보다 많을 수 있습니다.

비교 이력 보관

비교 이력 저장은 두 파일에서 읽은 데이터와 비교 설정을 이 PC 및 JSON 파일로 보관합니다. 저장 이력 불러오기 또는 JSON 파일로 다시 불러오면 현재 버전으로 재비교합니다. 원본 BOM이 수정됐다고 저장 이력이 자동 갱신되지는 않습니다. 다른 PC로 옮길 때는 JSON 파일을 사용하세요.

결과가 예상과 다를 때

  • 항목이 없으면 먼저 파일명·시트·제목 행·열 연결·제외 설정을 확인합니다.
  • 규격이 ‘Location만’이면 원본 규격과 PCB Decal을 직접 확인합니다.
  • 입력 점검과 중복 안내는 오류를 무시하라는 뜻이 아닙니다. 해당 원본 행을 먼저 확인합니다.
  • 파일·설정을 고친 후 비교를 다시 실행하고 새 결과를 저장합니다.
